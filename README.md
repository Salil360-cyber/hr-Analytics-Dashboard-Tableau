# HR Analytics Dashboard | Tableau

An interactive **HR Analytics Dashboard** built using **Tableau** to transform employee workforce data into meaningful business insights. The dashboard enables HR professionals to monitor employee demographics, attrition trends, workforce distribution, and job satisfaction through interactive visualizations, supporting data-driven HR decision-making.

## Project Overview 
Organizations generate large volumes of employee data every day, but extracting actionable insights from spreadsheets and static reports can be challenging. This project demonstrates how Tableau can be used to convert raw HR data into an interactive dashboard that helps HR teams understand workforce trends, identify high-risk employee groups, and support employee retention strategies.

## Project Objectives
- Develop an interactive HR Analytics Dashboard using Tableau.
- Analyse employee attrition across departments.
- Monitor workforce demographics and employee distribution.
- Evaluate job satisfaction across different job roles.
- Identify employee groups with higher attrition.
- Support HR decision-making using interactive dashboards.

## Key Business Insights

- Sales department recorded the highest employee attrition.
- Employees aged **25–34** experienced the highest attrition.
- Male employees showed higher attrition than female employees.
- Employees from **Life Sciences** and **Medical** education backgrounds contributed the highest attrition.
- Overall attrition rate was **16.12%**, highlighting opportunities to strengthen employee retention strategies.

4. Analyse workforce trends and employee attrition.
